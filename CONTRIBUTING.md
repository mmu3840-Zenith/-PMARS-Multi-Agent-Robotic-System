# Contributing to PMARS

Thank you for your interest in PMARS.

## Research Integrity

PMARS is a research-oriented simulation project. Contributions should:

- Clearly distinguish simulation results from physical-world validation.
- Preserve reproducibility.
- Document new experimental conditions.
- Avoid unsupported performance claims.
- Include tests when adding or modifying functionality.

## Development Workflow

1. Fork the repository.
2. Create a feature branch.
3. Make the change.
4. Run the test suite.
5. Run relevant experiments.
6. Document the change.
7. Submit a pull request.

## Reproducibility

When modifying experimental code, document:

- random seeds
- number of trials
- environment configuration
- evaluation metrics
- baseline configuration

Results should be generated by the experiment framework rather than manually entered.
